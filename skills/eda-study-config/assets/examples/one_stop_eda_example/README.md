# EDA 一站式示例

这是可复用的 EDA 一站式模板。示例使用参数占位符，不包含真实数据、真实研究名称、绝对路径或个人信息，也不包含特定行为结局的编码规则。

## 内容

- `one_stop_eda_example.py` 提供单入口、日志、断点、输入指纹、预处理、特征、统计、图表和 APA 交接清单的示例编排。
- `analysis_config.example.json` 记录需要由真实研究填写的输入、窗口、特征、统计和输出设置。
- `feature_definitions.example.csv` 展示 EDA 特征台账格式。
- `APA7_EDA_report_example.md` 展示 EDA 结果报告结构。数值、名称、路径和引用位置均为占位内容。

## 使用边界

把真实研究的绝对输入路径写入独立配置文件，再由执行器核对表头、单位、采样率、身份、时钟和输出目录。原始文件只读，运行目录每次单独创建。没有确认的设备单位、事件锚点或身份关系保留为待核对状态。

示例不代表任何设备或研究已经验证。正式运行前必须使用当前 EDA Toolkit 的契约、能力和真实输入完成校验。
