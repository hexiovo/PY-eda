# 方法指南

本指南描述 EDA Toolkit 0.2.0 当前可见的数据契约和算法实现。每个值都应结合其信号基础、支持区间、状态及来源解释。软件实现或合成数据通过检查，不证明默认参数适合某一设备、皮肤位置、实验任务或人群。

## 输入单位和时间

标准 record 有等长数组 time_s、eda_uS、sample_index，以及 metadata 和 extras。时间单位为秒，导电值为微西门子。CSV 按读取的同一组原始字节计算 SHA256 并解析；运行诊断报告编码、分隔符、字段映射、来源单位、采样率、时钟域和映射版本。输入文件不会被改写。

单位转换按显式声明执行：S × 10^6 转 uS，mS × 10^3 转 uS；正电阻 R_ohm 转 uS 的公式为 10^6/R_ohm，kΩ 和 MΩ 先换算为 Ω。零/负电阻和未知单位拒绝转换。自定义幅值列必须声明 eda_unit。只有标准列名 eda_uS 可按已约定名称解释为 uS。

若提供时间列，输入次序保留，时间必须有限、严格递增；重复、反向或缺失时间拒绝，不排序、不删除来制造单调序列。缺时间列时，需声明正采样率及 s/ms/us 的 time_unit；合成时间标记为推导值，不能还原未记录的设备丢样。采样率声明与时间戳估计分开记录。秒是单位，不表示两个设备时钟相同。

## QC facts 与人工审计

QC 输出是相互独立的布尔事实和从事实推导的 eligibility。当前实现能表达原始缺失、非有限值、自动候选、人工排除/恢复、插值、边缘影响及不可信时间等事实；候选原因可以重叠。平坦段使用真实持续时间和容差；导数/跳变基于实际 dt。较大的采样间隔切断连续段。

人工区间采用半开时间范围 [start,end)。记录有唯一 annotation_id、recording/channel、action、operator、reason、timestamp、revision 与 parent_revision。exclude 总是排除；restore 只能覆盖自动候选，不能恢复原始 NaN/Inf 或不可信时间。Undo/redo 是新历史行，不删除原操作；parent revision 冲突时拒绝。自动候选只是提示，不等于设备无效判定，阈值需由设备和任务先导数据确定。

## 分段预处理

预处理只在允许的连续支持内处理。短缺口可选线性或 PCHIP 插值，但必须有有效两侧支撑且跨度不超过配置限制；首尾不外推，长缺口切段。插值来源事实保留，主特征可按策略排除插值样本。

低通采用 SciPy Butterworth 二阶节（SOS）并以前后向运行；每段检查正采样率、Nyquist、padding 和最小段长。软件按数值容差估计保守边缘半径并传播 edge_affected；这描述本地离线算法的工程处理，不是普适的生理可用时长保证。Polyphase 重采样按连续段分别处理、抗混叠且传播被触及的质量事实。基线减均值保持物理差值；缩放写入独立 analysis_signal，clean_uS 仍保留物理单位。

缺失不等于零，长缺口不桥接，最后一个样本不向前外推形成额外曝光。时间加权积分仅累计两个端点均合格、跨度未超过 gap 限制且与半开窗口相交的相邻区间。

## Tonic / phasic filter separation

基础分解名为 filter_separation。本地实现用 SciPy 二阶 Butterworth SOS 对 clean_uS 分别作低通与高通，得到 tonic_uS 和 phasic_uS；报告记录 cutoff、order、采样率、每段状态和边缘影响。residual_uS 明确定义为 clean_uS − tonic_uS − phasic_uS，driver 为 None。独立滤波分量不承诺精确重构信号。

这不是 NeuroKit2、cvxEDA 或 Ledalab 的兼容实现。当前演示默认示例值为 0.05 Hz、二阶，仍需按不同采样率、频率响应、缺口与任务作独立数值和科学验证。

## SCR 候选、阈值和起点支持

trough_to_peak 在每一条完整 detector-eligible 连续段中寻找 trough、peak 与恢复候选。peak 平台取最早最大点，rise_time_s 是峰时间减 trough 时间。检测器先收集整条记录的上升候选，再应用阈值；相对阈值的参考范围是整条记录合格 rise 候选的最大幅值，不在窗口内重新计算。绝对幅值阈值的单位为 uS，且只能用于明确的物理 uS 信号基础。

最小响应间隔按 onset_s 冲突；冲突时保留幅值较大的响应，相同时保留峰更早者。恢复阈值为 L+(1−f)A，其中 L 为 onset 水平，A 为峰相对 onset 的幅值，f 为配置的“返回比例”。首次向下穿越由相邻样本线性插值。新响应、坏段、长缺口或记录结束前未穿越时，recovery 标记删失；该删失不抹去已经合格的起点、幅值或计数。

SCR 面积从 onset 到 peak 积分，以 onset level 为零基线，采用有符号梯形法，单位为 uS·s。scr_area_sum_uS_s / scr_area_mean_uS_s 汇总合格起点响应；event_scr_area_sum_uS_s 按唯一 event_scr_links 归属汇总事件响应窗内的响应。该面积只表示已观察的上升段，不外推到恢复段；恢复删失不影响已观察的上升面积。曝光不足、事件支持不足或面积目录缺失时显式返回 unavailable。

起点上下文和候选搜索是分开的。scr.onset_left_context_s 默认为 0 秒；scr.onset_right_context_s 默认为 max_rise_s，显式右上下文不能短于 max_rise_s。上下文资格按实际时间和同一连续段检查，不只按“有多少样本”判断。

整个连续段仍用于 trough、peak 和 recovery 搜索。单独的 onset_eligible 字段决定候选是否进入主计数、rate 与幅值摘要；目录保留全部候选。上下文不足的目录项带 qualification_reason=unavailable_onset_context，不伪装成“没有响应”。这允许记录边界附近的早起点仍在后续 tail 中找到峰或恢复，而其计数资格和 recovery censoring 分别判断。

计数/率使用起点合格支持上的半开时间曝光，逐个累计相邻合格时间区间，不跨 gap、不外推尾点。若窗口并未被起点支持完整覆盖，不能声称该窗口没有 SCR；无合格曝光时 SCR count/rate 为 unavailable，而不是 0。

默认示例阈值（如 0.05 uS 幅值、0–10 秒上升和 1 秒最小间隔）可配置，未按设备、皮肤接触、采样率或任务刺激校准。论文或设备参数只可作为有来源的比较条件，不自动成为本软件推荐值。

## 分析窗与特征

窗口类别为 whole、fixed、event 和 condition，边界均为 [start,end)。事件 baseline、response、peak、recovery 是分别配置和校验的时间范围。跨段、响应重叠或起点归属不唯一时，事件特征保留 ambiguous/invalid/unavailable 状态和原因。

样本统计（mean、median、sd、IQR 等）按所选合格样本计算，不等同于时间加权统计；分位数使用线性 percentile method。`iqr=Q75-Q25` 对一个合格样本定义为 0，最低样本数为 1；其他指标依各自登记的 `min_n` 判断。phasic_auc 是裁剪到窗口的有符号梯形积分，单位 uS·s；slope 用实际时间作最小二乘。valid_sample_proportion、interpolated_sample_proportion 和 artifact_sample_proportion 是样本计数比例，不是时长比例。原有 33 项的固定 ID、单位、basis 与公式列于 [v0.1 特征字典](特征字典.csv)；schema 1.1 完整能力目录及新增方法定义列于 [v1.1 特征字典](特征字典-v1.1.csv) 与 [扩展指标与结果表](扩展指标与结果表-v1.1.md)。具体动态频带/滞后参数以单次运行冻结的 `feature_definitions.json` 为准。

“成功窗口内没有符合阈值的响应”只有在起点支持完整、曝光可用时才表示 count=0；平均幅值因没有响应而 unavailable。缺少恢复时间时恢复摘要可为 censored/unavailable，不会改变起点摘要。

## 多人时钟和同步

跨记录的时钟映射使用独立同步锚点拟合 t_ref=a+b·t_local，要求 b>0，并据此转换采样率 fs_ref=fs_local/b。单锚点只支持偏移；没有足够锚点时不从 EDA 信号相关性猜同步。关联事件/条件/注释/锚点也必须声明时钟域。映射残差、跨度、外推与时钟质量应在解释群体指标前检查。

同步相关的 lag 符号约定为正 lag 表示 A 领先 B：计算 corr(A(t), B(t+lag))。观测窗口和 lag 要求使用相同的有效支持规则；组汇总固定成员/边集合并报告覆盖。`sync_lag_sd_s` 与 `sync_lag_stability_proportion` 按窗口中心划分非重叠 midpoint time cells，并以每个 cell 与该 pair 连续合格支持相交后的实际时长为权重，不按重叠原窗宽计权。缺口保留为未知；先逐 pair 计算，再对有效 pair 等权汇总。标准差使用总体加权定义（`ddof=0`），稳定比例以加权中位数为中心。三个中心为 2、4、8 秒的窗口对应 cell 权重 3、3、4 秒；selected lag 为 0、0、2 秒时加权 SD 为 `sqrt(0.96)=0.9797958971` 秒，容差 1 秒的稳定比例为 0.6。

Node strength 的预期 degree 来自冻结的成员 roster/完整预定图，不随某一窗口实际出现的边数缩小。三人完全图的每个节点 `expected_degree=2`；若 BC 边缺失，B、C 的节点强度（包括标准化强度）为 `NA_missing_fixed_incident_edge`，A 在 AB 和 AC 均有效时仍可计算。没有 roster 或预定边集合时返回 `NA_expected_graph_unknown`。群体固定边汇总仍按缺失边规则标记不可用。组均值、配对边和 leave-one-out 不应被误读为独立被试数。

Surrogate/null 仅用于探索。approved 修复定义要求显式分析半开区间；如果未指定区间，则按声明的 analysis_context_s 从对齐共同网格两端裁去上下文。观测与 surrogate 在同一解析区间执行相同的多窗口/多 lag 搜索。循环位移先按每个成员构造全体窗口、lag 与接缝剔除所需支持；接缝必须不落在使用位置，移动前后掩码在这些位置逐点相同。每位参与者对所有通道/窗口/指标使用同一位移。全覆盖下接缝不可能时应预检 unavailable，不靠降低请求重复数换取成功。

双侧尾统计在 lag 上比较 max(abs(r))，greater 比较 max(r)，less 比较 min(r)；观测和每个 surrogate 重复相同的搜索并保留有符号 r 与选中 lag。输出应标记 surrogate_tail_probability / experimental_uncalibrated 并报告 Monte Carlo 不确定性。加一校正公式本身不能证明零假设可交换性或 p 值已校准；不能把此数称为已校准显著性。

Pseudodyad 需真正重分配 donor，而不是退化为 circular shift。仅在可交换性明确、task/stimulus 时间线或 strata、唯一 role/member_slot、完整匹配块及 task-relative time 均满足时使用。目标记录保持目标身份，保留 donor 来源，拒绝自配、原配、同一互动块及支持不匹配；缺少这些元数据时返回具名 unavailable，不回退到别的方法。该路线和所有 null 的科学校准仍待验证。

## 统计单位和假设

统计输入是长表特征，不应把同一参与者的多个事件/窗口当作独立被试。设计必须显式声明独立单位、条件/组/会话字段、预定 outcome、contrast 和多重比较 correction_family。混合模型的随机截距层级须符合采样结构；被试是实验单位时，应先按预定义规则处理窗口/事件层级或采用对应重复测量模型。

统计接口使用结构化字段，拒绝用户公式/任意代码。预定检验家族中失败或不可用的项仍需保留状态，不能运行后缩小 family。报告估计量、效应、标准误、置信区间、统计量、df、p/调整后 p、独立单位数、排除数和诊断；应阅读随机效应/残差诊断并检查设计是否可识别。IR02 的未声明条件水平、IR03 的计划混合模型系数家族保留原反例均有定向通过证据；最终源码的完整模型设计与诊断覆盖尚未全部完成。

## 能力状态

filter_separation 当前可用但 readiness 为 research；代表性真实数据和设备/task 资格仍 pending。cvxEDA、Ledalab 和 GPU 后端目前为 disabled；其缺失依赖/许可、数值比较和性能证据没有满足启用门槛时会明确失败，不静默替换基础方法。研究解释限制见 [验证与限制](验证与限制.md)。
