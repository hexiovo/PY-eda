# EDA Toolkit 中文工作台界面设计

## 目标与使用边界

工作台将数据导入、质量控制、预处理、SCR、多人同步、统计设计和结果检查放在同一套本地桌面界面中。它面向逐步配置和重复运行的研究流程，不把默认研究参数描述成设备认证参数或科学结论。项目数据和运行结果保留在用户选择的本地路径。

每次启动分析时，界面先校验并深复制完整配置。运行中的窗口锁住配置编辑控件，pipeline 只接收这个快照；取消请求通过线程安全事件发送到 pipeline 检查点。进度回调只写线程安全队列，主线程 QTimer 负责更新控件、状态和日志。

## 布局与导航

主窗口默认约 1420 × 920，可缩放，最小尺寸 1120 × 760。顶部放置产品标识、五种流程预设和常用动作；左侧固定宽度导航切换八个步骤页；右侧内容可滚动；底部固定显示进度、运行状态和最近日志。

八个页面按实际工作顺序组织：

1. **项目**：输出目录、完整 JSON 配置、能力状态、工程合成数据。
2. **导入与映射**：九类 core_io 模板、文件有界预览、实际信号列映射与读取诊断。
3. **质控**：原始曲线、自动候选、时间段选择、人工排除/恢复及审计撤销/重做。
4. **预处理**：短缺口插值、平滑、低通、重采样、边缘容差、固定基线和缩放分支。
5. **分解与 SCR**：分解方法、截止频率、阈值、上升时间、恢复定义和 onset 左/右上下文。右上下文至少覆盖最长上升时间；边缘候选保留供审阅，但不进入主计数。
6. **多人同步**：共享基线、时滞网格、覆盖、Null 方法和时钟资格声明。
7. **统计设计**：结构化设计 JSON、独立单位、结果变量与多重比较校正。
8. **结果**：运行摘要、表格行数和预览、图片、HTML 报告、文件副本及缓存校验恢复。

## 视觉规范

使用灰蓝色页面背景 `#F4F7FA`、白色内容卡片、深蓝文字 `#17324D` 和青绿色主操作 `#087E83`。暖橙用于响应标记，红色只表达排除、失败或错误。卡片之间保持清晰间距，边框轻量，标题通过字号和字重区分层级。基础文字约 11 pt，辅助说明约 10 pt；界面优先加载 Windows 微软雅黑，兼容时回退到系统可用的中文字体。

常用操作使用文字按钮而不是仅图标；主运行、取消和错误状态有稳定位置。输入旁边标出秒、Hz、μS、相对比例等单位。未声明的单位显示为“未声明”，不自动转换或猜测。范围选择统一采用半开区间 `[start,end)`，固定窗尾策略和窗口覆盖状态在对应参数旁展示。

## 交互状态

- **就绪**：显示当前预设及“研究示例、尚未科学资格验证”的状态。
- **读取/预览**：用真实 core_io API 加载，进度消息区分文件、记录和映射；预览行数有界，同时报告源表总行数。
- **运行中**：配置页和启动动作锁定；取消按钮可用；底部展示当前 stage、record 和已完成数量。
- **完成/部分/失败/取消**：结果页展示 pipeline 实际 summary，不把缺表或缺图绘成零值；partial 和失败运行支持调用 `resume_run` 做缓存与输入完整性校验。
- **错误**：日志保留稳定错误码及可用的字段、阶段和修正建议；帮助菜单可打开内置中文 PDF 或显示预期资源路径。

## 数据流与真实性

模板查看和下载调用 `core_io.read_template` / `export_template`；外部 CSV 列预览调用 `preview_csv`；信号映射预览调用 `read_signal_csv`。GUI 不另写 CSV 解析或信号换算逻辑。实际运行只调用 `pipeline.run_pipeline` 或 `pipeline.resume_run`。

质控标注调用 `append_annotation`、`undo_annotation`、`redo_annotation` 与 `build_quality_mask`。人工决定保存操作者、时间、原因、时钟域和父版本，并写入新运行配置。已有 `input.manual_qc` 与 `qc.annotations` 同时存在时，界面拒绝继续追加，以免静默丢弃或重排两份审计历史。

结果图形由无 pyplot 状态的 Matplotlib Figure 生成。没有同步结果时跳过同步图；只有 null 摘要时展示实际导出的均值、标准差与观察值，不构造虚假 surrogate 直方图。图片查看、HTML 打开、运行目录打开和单文件副本导出均作用于真实产物。

## 可访问性与键盘操作

导航采用标准 `QListWidget` / `QStackedWidget`，常用按钮可由 Tab 聚焦，帮助绑定 F1。状态信息使用文本，不仅依赖颜色。输入范围和失败状态通过文字标签补充，长说明允许换行，表格启用选行和交替底色。运行期间禁用配置编辑，避免操作者误以为变更会影响已冻结快照。

## 工程合成演示

“创建并载入合成演示”只在输出目录下建立空的 `synthetic_demo` 子目录；若目标目录已有内容，创建操作失败且不覆盖文件。生成的信号和伴随表标注 `SYNTHETIC_ONLY`。工程合成数据用于检查导入、计算、绘图和导出通路，不能代表真实设备、个体或研究任务的科学效度。
