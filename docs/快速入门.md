# 快速入门

适用版本：EDA Toolkit v0.3.1。本文说明 Windows 便携版和源码环境的启动方式，并通过合成数据走一遍命令行流程。开始处理真实研究数据前，请阅读[方法指南](方法指南.md)和[验证与限制](验证与限制.md)。

## 1. 下载并启动 Windows 便携版

在 [v0.3.1 发布页](https://github.com/hexiovo/PY-eda/releases/tag/v0.3.1)查看发行信息，或直接下载 [Windows x64 便携版](https://github.com/hexiovo/PY-eda/releases/download/v0.3.1/EDA_Toolkit-0.3.1-Windows-x64.zip)。解压后，在解压目录中双击 eda_gui.exe 启动图形界面；同目录下的 eda_cli.exe 是命令行入口。

请保留整个解压目录，不要单独移动 EXE。运行所需内容包括 _internal、third_party，以及 docs、assets、presets 和 skills 等文件夹。便携版不需要另行安装 Python、MATLAB 或 CUDA。

在解压目录中打开 PowerShell，确认当前执行器版本：

~~~powershell
& '.\eda_cli.exe' version --json
~~~

## 2. 使用源码环境

源码环境需要 Python 3.11 或更新版本。在项目目录打开 PowerShell，创建虚拟环境并安装项目：

~~~powershell
python -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install .
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit --help
~~~

查看版本和可用能力：

~~~powershell
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit version
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit capabilities --json
~~~

依赖版本及来源记录见 [requirements.lock.txt](../requirements.lock.txt) 和 [provenance](provenance.md)。

## 3. 运行合成演示

合成演示用于熟悉导入、计算和导出流程，不代表真实设备数据，也不用于证明某种方法适合研究。以下示例适用于 Windows 便携版：在 eda_cli.exe 所在目录打开 PowerShell。命令会在当前 Windows 用户的“文档”目录下创建一个新的演示目录；如果该目录已存在，请换一个新名称。脚本不会删除已存在的目录。

~~~powershell
$demoDirectory = Join-Path $env:USERPROFILE 'Documents\EDA演示临时-v0.3.1'
& '.\eda_cli.exe' demo --directory $demoDirectory
if ($LASTEXITCODE -ne 0) { throw '演示数据生成失败。' }

$configPath = Join-Path $demoDirectory 'single.json'
& '.\eda_cli.exe' validate --config $configPath --json
if ($LASTEXITCODE -ne 0) { throw '演示配置检查失败。' }
& '.\eda_cli.exe' plan --config $configPath --json
if ($LASTEXITCODE -ne 0) { throw '演示计划检查失败。' }
& '.\eda_cli.exe' run --config $configPath --json
if ($LASTEXITCODE -ne 0) { throw '演示运行失败。' }
~~~

源码环境可用同样的 CLI 子命令。将上例中的 eda_cli.exe 调用替换为以下形式，并保留相同的参数：

~~~powershell
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit demo --directory $demoDirectory
if ($LASTEXITCODE -ne 0) { throw '演示数据生成失败。' }
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit validate --config $configPath --json
if ($LASTEXITCODE -ne 0) { throw '演示配置检查失败。' }
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit plan --config $configPath --json
if ($LASTEXITCODE -ne 0) { throw '演示计划检查失败。' }
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit run --config $configPath --json
if ($LASTEXITCODE -ne 0) { throw '演示运行失败。' }
~~~

源码目录还提供固定种子的 examples/synthetic_demo 演示数据，含四条 4 Hz、600 秒记录及事件、条件、成员和同步锚点。数据标记为 SYNTHETIC_ONLY，用于检查工程流程，不用于展示科学效应。运行结果中的 science_qualification 为 pending_representative_real_data，表示真实代表性数据仍未核验。合成数据中的行数、阈值和事件数量都不能作为仪器规范。

## 4. 分析自己的数据

1. 从适用的 JSON 预设开始，保留完整配置；在 input 中声明信号文件或 manifest 路径，在 mapping 中填写列名、单位、采样率和时钟域。
2. 按 [CSV 字段字典](CSV字段字典.md)准备信号、参与者、事件、条件及所需的关联表。只提供当前分析需要的表。
3. 先运行 validate，阅读完整导入报告和诊断。时间重复、倒退或缺失时，程序会报告问题，不会自动排序或删除样本；单位未知时，应先查明来源再填写。
4. 运行 plan，核对启用阶段、有效时长、映射及能力门槛。确认配置和输入正确后，再运行 run。
5. 将结果写入新的运行目录，保存完整 JSON 输出、来源目录和 manifest。不要覆盖原始输入或已有分析结果。

时间列缺省时，必须提供采样率和 time_unit。软件会据此生成推导时间，但无法还原设备漏采的信息。幅值 NaN 会作为缺失值保留，不会转换成 0。自定义幅值列须显式声明 eda_unit；标准列名 eda_uS 按 uS 解释。

validate、plan 和 run 对应同一执行 pipeline 的不同步骤。运行前应核对各命令的状态与诊断，不要只依据退出码判断研究已就绪。

## 5. 启动图形界面

便携版在解压目录中双击 eda_gui.exe。源码环境可运行：

~~~powershell
& '.\.venv\Scripts\python.exe' -X utf8 -m eda_toolkit.ui.app
~~~

如果已激活源码虚拟环境，也可使用 eda-gui 命令。首页的“在输出目录创建并载入合成演示”会创建新的 SYNTHETIC_ONLY 示例目录；“单文件试跑”“批量启动”“取消运行”调用同一 pipeline。真实数据操作顺序与界面说明见[操作指南](操作指南.md)。

## 6. 查看结果与相关说明

运行目录包括 resolved_config.json、provenance.json、summary.json、manifest.json、HTML 报告、结果表和图像。结果表可按运行命令指定的格式导出为 CSV、JSON 或 XLSX；图像为 PNG。manifest 记录导出产物的大小和 SHA256；resume 会检查已提交缓存及输入是否发生变化。

schema 1.1 的扩展指标和附属表见[扩展指标与结果表](扩展指标与结果表-v1.1.md)及[完整指标字典](特征字典-v1.1.csv)。旧版[特征字典](特征字典.csv)保留 v0.1 的 33 项定义。结果页查看本次运行的指标定义时，使用该运行保存的 feature_definitions.json、配置和 manifest 表头；查看历史运行时也以对应历史文件为准，不用当前编辑器草稿重新解释动态指标。

报告会列出不可用、删失和歧义等状态及原因。缺失的估计值不代表 0；单凭一次运行成功也不能判断研究假设是否成立。更多说明见[方法指南](方法指南.md)和[验证与限制](验证与限制.md)。

## 7. 安装配置技能

研究设计配置技能的作用、安装步骤和使用示例见[技能说明](../skills/README.md)。在源码目录运行 `skills/install_skill.ps1`；解压技能压缩包后，在解压目录运行 `install_skill.ps1`。技能安装后请开始新的 Codex 对话；若技能没有显示，重启 Codex 后再新开对话。
