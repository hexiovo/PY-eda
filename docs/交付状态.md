# v0.3.1 交付说明

EDA Toolkit v0.3.1 提供 Windows x64 双入口便携压缩包和独立的 `eda-study-config` 技能包。便携包内含图形界面 `eda_gui.exe`、命令行入口 `eda_cli.exe`、运行文件、预设、中文手册和第三方组件清单；技能包提供实验设计配置助手所需的说明、参考、模板和脚本。

下载后先解压完整压缩包。使用图形界面时双击 `eda_gui.exe`；使用命令行时在同一目录运行 `eda_cli.exe`。不要单独移动 EXE，也不要删除 `_internal`、`third_party`、`docs`、`assets` 或 `presets`。

当前发行包、技能包、发布说明和 SHA256 校验值位于 [GitHub Releases](https://github.com/hexiovo/PY-eda/releases/latest)。本地压缩包内的 `release_manifest.json` 列出便携目录文件及两个 EXE 的 SHA256。

软件工程验证只说明被检查的软件版本和运行环境中的工程行为。它不证明真实设备适用性、统计模型假设、研究结论或临床有效性。具体边界见[验证与限制](验证与限制.md)。
