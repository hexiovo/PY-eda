## 已实现的主要流程

输入映射与模板 → 项目草稿自动保存与恢复 → 运行前检查 → 显式队列启动、任务历史及持久化日志 → marker 导入/编辑/审计 → QC 与连续段预处理 → 分解、SCR 与扩展特征 → 多人同步和统计 → CSV、JSON、XLSX、HTML、图片、PDF 与 manifest 导出。

扩展结果包括时域与 SCR 分布/恢复/ISI 指标、trial 响应与 habituation 描述、覆盖限定的 non-specific SCR、Welch 频谱/带功率、自相关、复杂度以及 group temporal 输出。配置、指标状态、有效支持、诊断表和方法元数据随结果保存。v1.0 配置按兼容规则迁移到内存中的 v1.1 结构；旧运行仍按其自身配置和方法版本读取。

cvxEDA、Ledalab 和 GPU 仍为禁用能力；选择它们会明确拒绝，不会静默替换算法。研究参数与公式不代表真实设备或任务适用性。
