## 实现状态与适用性

原 33 个指标保留兼容语义。启用扩展的 single 配置当前解析 90 个适用指标；group temporal 仅在同步启用的 group 配置可用，全能力注册表共 101 个 ID。频谱与自相关动态 ID 还受显式频带和 lag 配置影响。关闭扩展时保留 legacy 33。每个结果应结合其 status、reason、有效样本/时长、配置和对应诊断表解释；不可用、缺支持、删失或实验状态不能当作数值零。

新增统计、频谱/复杂度和多人时间特征按计划实现并有定向手算/合成回归，但仍属工程/研究功能。SCR 默认阈值、窗口、覆盖门槛、滤波参数、Welch频带、复杂度参数、trial 分类和同步阈值不是通用生理标准。null/surrogate 的状态保留 `experimental_uncalibrated`；玩具数据重复诊断样本有限，不能据此宣称类型 I 错误控制、真实任务校准或确认性检验。

分解为独立 SciPy 实现；不声称与 NeuroKit、cvxEDA 或 Ledalab 算法兼容或结果等价。cvxEDA、Ledalab 与 GPU 当前禁用；界面/CLI会明确拒绝不可用能力，不自动切换到另一算法。软件不会输出压力、情绪、疾病或诊断结论。
