# 验证范围与使用限制

本文适用于 EDA Toolkit v0.3.1。工程运行、数据质量和科学适用性是不同问题；任何一项通过，都不能替代另外两项。

## 工程使用

Windows x64 便携包包含图形界面、命令行程序和随包运行文件。下载后应解压完整目录，并从该目录启动 `eda_gui.exe` 或 `eda_cli.exe`。发布页列出本版本的压缩包、SHA256 校验值和实际工程验证结果。

启动成功只表示程序能够运行；输入能通过检查只表示该输入符合软件契约。它们都不证明设备、预处理参数或研究结论已经获得科学验证。尚未在全新安装环境验证的事项，会在相应发布记录中明确说明。

## 数据与科学边界

- 附带示例是固定生成的 `SYNTHETIC_ONLY` 合成数据，只用于熟悉界面、验证软件流程和查看输出格式，不是真实被试记录，也不代表任何研究效应。
- 采样率、设备单位、时钟来源、滤波频率、SCR 阈值、分析窗口及统计设计必须由实际设备资料、研究方案和合适的先导数据决定。软件默认值不应直接当作设备建议或文献结论。
- `bateman_sparse` 是本地实现，不是 Ledalab/CDA 或 cvxEDA 的复现。默认 `filter_separation` 是 SciPy 独立低通/高通滤波分离，也不等同于其它软件的同名方法。
- 同步 surrogate/null 的可达性、交换性和尾部概率尚未获得真实任务的校准证据；相关输出会保留实验性状态。不可用、删失或歧义结果不能解释为零响应或没有效应。
- 分析输出中的 `succeeded` 表示软件流程完成，不代表质量审查、统计模型诊断或研究假设已通过。

本软件不作压力、情绪或疾病判断，也不替代生理信号质量评估、研究设计、伦理审查或专业统计判断。

## 隐私、来源与分发

核心分析流程在本机读取输入并写入用户指定的输出目录。运行时请勿将结果目录存放在未经授权的共享位置，并按研究机构要求管理原始数据和导出结果。

压缩包提供依赖版本、第三方组件清单和可取得的许可证文本副本，供用户核对实际制品。该清单是构建库存，不是法律意见或分发义务已获批准的证明。中文 PDF 使用随包附带 OFL 许可证文本的 Noto Sans SC 字体。
