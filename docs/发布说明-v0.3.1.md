# EDA Toolkit v0.3.1

## 下载

- `EDA_Toolkit-0.3.1-Windows-x64.zip`：Windows x64 双入口便携版，包含图形界面、命令行程序、运行文件、预设和中文手册。
- `eda-study-config-0.3.1.zip`：实验设计配置技能，包含使用说明、参考资料、配置模板、校验脚本及 Windows 安装说明。
- `SHA256SUMS.txt`：上述两个压缩包的 SHA256 校验值。

## 本版调整

- 统一软件与 Windows 程序版本为 v0.3.1。
- 窗口与启动提示采用稳定的产品名称，移除面向开发过程的 UI 修订标记。
- 更新 Windows 下载、解压和启动说明；重新生成中文 PDF 手册及当前界面截图。
- 发布完整 `eda-study-config` 技能包，不含临时缓存和验证摘要报告。
- 便携压缩包包含 `release_manifest.json`，列出目录文件及图形界面、命令行 EXE 的 SHA256。

## 使用边界

演示数据是 `SYNTHETIC_ONLY`，不是真实研究记录。软件运行成功或工程测试通过，不代表参数已按设备校准、统计推断已验证或研究结论成立。请阅读随包提供的[验证与限制](验证与限制.md)和[方法指南](方法指南.md)。
